# prj-entrades-a23marrojgon Constitution

## Core Principles

### I. Unified Modern Stack
El proyecto se basa en una arquitectura de tres capas: Frontend con Next.js/React/TypeScript, Backend API con Laravel (PHP) y comunicación en tiempo real con Node.js/Socket.io. Se utiliza Tailwind CSS v4 para garantizar una estética moderna y coherente.

### II. Code Integrity & Language Consistency
Los comentarios en el código deben estar en Español para facilitar la comprensión interna del equipo, mientras que los nombres de variables, funciones y archivos deben estar en Inglés. No se debe borrar código existente a menos que sea estrictamente necesario.

### III. Modularity & Responsiveness
Cada nueva funcionalidad debe ser modular y reutilizable. El diseño debe seguir una estrategia "Mobile First", asegurando que todas las interfaces sean totalmente responsivas y funcionales en dispositivos móviles.

### IV. Relative Pathing & Standard Structure
Todas las rutas de archivos deben ser relativas. Se debe respetar la estructura de carpetas definida: `api/`, `client/`, `socket/`, `.specify/` y `.agent/`.

### V. User-Centric Premium Design
La interfaz debe ser limpia, intuitiva y accesible. El objetivo es proporcionar una experiencia de usuario fluida para la compra de entradas, utilizando contrastes adecuados y micro-animaciones (Rich Aesthetics).

## Stack Tecnológico
- **Frontend:** Next.js (App Router), React, TypeScript.
- **Backend:** Laravel (API), Node.js (Socket.io).
- **Styling:** Tailwind CSS v4, Vanilla CSS (Flexbox/Grid).

## Governance
Toda modificación de estos principios debe ser documentada y aprobada. El cumplimiento de estas reglas es obligatorio para mantener la coherencia y calidad del proyecto.
