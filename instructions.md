# Constitución del Proyecto: prj-entrades-a23marrojgon

## 1. Stack Tecnológico
- **Frontend:** Next.js (App Router), React, TypeScript.
- **Estilos:** Tailwind CSS v4 para el diseño; Flexbox/Grid nativo para estructuras.
- **Backend:** Laravel (PHP) para la API principal y Node.js para el servidor de Sockets.
- **Idioma:** Los comentarios en el código deben estar en Español, pero los nombres de variables y funciones en Inglés.

## 2. Reglas de Desarrollo
- No borres código existente a menos que sea estrictamente necesario para cumplir una especificación.
- Cada nueva funcionalidad debe ser modular y reutilizable.
- Asegúrate de que todas las páginas sean responsivas (Mobile First).
- Las rutas de los archivos deben ser siempre relativas.

## 3. Preferencias de Interfaz
- El diseño debe ser limpio e intuitivo para la compra de entradas.
- Usar colores accesibles, buen contraste y una estética moderna (Rich Aesthetics).

## 4. Estructura de Carpetas
- `.specify/`: Gestión de especificaciones, planes y memoria del proyecto.
- `.agent/`: Configuración del sistema y skills de IA.
- `api/`: Lógica del backend (Laravel).
- `client/`: Aplicación frontend (Next.js).
- `socket/`: Servidor de tiempo real (Node.js).
